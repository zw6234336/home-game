# 童话奇遇素材

使用内置 `image_gen` 生成的透明 PNG 原图保存在 `originals/`。完整提示词、运行文件路径、尺寸、字节数和校验值记录于 `prompts.json`。

运行素材位于 `public/art/storybook-v1/`：五个物品采用 384×384 WebP，两个头部面具采用 512×512 WebP。保留透明通道；原图不随网页发布。统一为柔和立体童话玩具风，沿用薰衣草紫、珊瑚粉、薄荷绿与暖金色。

水晶鞋与包包 10 分、公主裙 20 分、皇冠 30 分；原爱心仍穿插出现。炸弹沿用扣 20 分的规则，随机变小黑脸、小驴脸或小猪脸。面具由现有姿态关键点驱动，不进行身份识别，不增加 AI 模型。

`src/art/catalog.ts` 是运行时素材目录。`src/platform/game-art.ts` 只加载/解码一次；未就绪或失败时仍使用原有 Canvas 图形。`FaceEffects` 只消耗有效游戏时间，因此暂停和恢复倒计时保留变身时间。原图与提示词可在后续游戏中复用。

鼠标试玩右上角的演示头像用于体验变身，并不代表实际人脸追踪精度。
