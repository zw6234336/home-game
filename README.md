# 一起玩 · Home Game

面向电视的家庭体感游戏。五款玩法：泡泡派对、默契模仿秀、爱心雨、太空穿越门、彩虹能量桥。1～2 人合作，默认小手模式。索尼 PS4 体感摄像头连接 Omarchy 笔记本，HDMI 输出电视。视频和姿态均在本机处理，不使用麦克风、不录像、不上传。

## 本地运行

需要 Node 24。首次安装需网络下载依赖和官方模型，之后运行不依赖 CDN。

~~~sh
npm ci
npm run assets
npm run dev
~~~

打开 http://127.0.0.1:5173 。正式构建：

~~~sh
npm run build
npm start
~~~

打开 http://127.0.0.1:4173 。开发与预览服务仅监听 loopback。请勿通过改变host参数直接暴露到公网；此本地游戏不含在线身份系统。

## 首次设置

1. 在 Omarchy 完成摄像头固件加载并确认系统已可出画面。此项目不修改系统驱动、不自动注入固件。
2. 点击“连接摄像头”，在浏览器允许摄像头访问后自动启动本地识别。默认设备不符时可在镜头设置中更换。
3. 对照画面确认单眼裁剪。PS4原始格式可能包含双目、头部和额外区域，不能盲目裁半。可调整ROI的起点与宽高，画面只应出现一份人物。
4. 用HDMI连接电视，系统选择电视音频输出。初次全屏需要点击按钮或使用浏览器F11。
5. 每位玩家在舒服的位置、肩旁举手2秒确认。画面中手光点跟着自己移动，确认后开始。

授权后，抬手指向菜单并停留1秒可选择。泡泡派对可双手举起 1.5 秒或空格暂停；模仿秀通过手势指向「歇一下」停留 1 秒或空格暂停，举双手属于挑战动作。恢复有3秒倒计时。看不清手指时使用手腕，不要求复杂指法。需要重新选择设备或裁剪时由成年人操作。

泡泡派对提供“鼠标体验”，模仿秀提供“按钮演示”：分别点击两位伙伴的模拟按钮，体验各自保持、等同伴和共同过关。演示有显著标识，不代表摄像头识别结果。

## 默契模仿秀

在大厅选择第二款游戏，沿用相同设备检查和举手校准。照着小飞机、小星星、大力士、小屋顶、抱抱熊、招招手六张示范卡，只模仿上半身，双脚站稳。大人和小孩按各自肩宽、肩轴与手臂角度判定，不需要手指识别。

小手模式每张 20 秒、保持 1 秒；标准模式每张 16 秒、保持 1.4 秒。双人各自完成后共同得 100 分，先完成可等待同伴；离开画面的玩家需要重新完成。超时不扣分，暂停后也可换个动作。轻微远近和横向移动会自动适配；换人或长时间离开后需重新确认并开始新一局，返回大厅可保留已授权摄像头连接再选择其他游戏。

模仿秀复用现有姿态 Worker，每个有效采集帧只做轻量几何比较，游戏中关闭额外手部模型。暂停菜单仍支持手势。低置信点、重复帧或长断帧不能累计保持进度，未收到新鲜有效姿态时题目计时冻结；持续丢失会暂停。

## 小客厅与智能适配

大厅默认“自动适应”，根据肩髋可见性、画面边缘和两人伸手余量选择动作范围；也可选择“小客厅”，为镜头无法判断的沙发、墙边等限制保留较小动作。半身入镜即可，不要求脚部可见。无需输入房间面积，不测量物理距离。

两秒确认后，连续可信的同一玩家位置与尺度会更新校准，泡泡新出生范围随之变化；范围外的旧泡泡安静退出，不计漏接。突然跳变、换人或超过500ms缺少可靠身体观测会失效，不能靠重复异常位置继承另一人的范围。

显示取景使用双人可见关键点的并集、死区与平滑跟随，适度放大远处人物；新增伸展或掉人时及时扩大画面。采集单眼ROI始终固定，显示缩放不能找回镜头外的肢体。视频、骨骼与泡泡使用同一镜像坐标，手运动和泡泡半径保持源图比例，缩放不会制造扫击。

小客厅模仿秀包含小翅膀、小星光、小力士、小帐篷、抱抱熊、悄悄招手，主要在肩旁和胸前完成；每局固定动作版本，保持和计分规则与标准版本一致。菜单映射到肩旁较小的活动范围，继续支持停留1秒选中、放下手后再次选择。

以上适配只用现有姿态结果和轻量几何，不增加AI模型或后台服务。精细动作、遮挡鲁棒性、连续使用舒适度和真实电视延迟仍需接入PS4及目标客厅验证。

## 质量与延迟

默认高质量：Full Pose、960长边采样、目标30次/秒。均衡：Lite/640/24；流畅：Lite/480/20。帧率是调度上限，不是设备性能承诺。画面绘制独立运行，识别Worker只保留一帧在途，超过150ms结果不计分。菜单启用精细手部识别，游戏中可选增强。

诊断显示渲染/识别频率、推理耗时与结果年龄；这些都不是“动作到电视”的物理延迟。目标PS4相机/Omarchy/HDMI尚未在当前开发环境验收，i5代际未知；1080p双人10分钟和高帧率相机测量仍需实机完成。可使用均衡档兼容当前集显，后续升级直接切高质量。

## 摄像头诊断

在目标Linux执行只读检查：

~~~sh
bash scripts/diagnose-camera.sh
~~~

需要工具时由系统管理员安装usbutils/v4l-utils。不要只按一个USB ID判断摄像头已就绪，也不要默认/dev/video0是PS4。先查看实际分辨率和帧率，再确认浏览器实际videoWidth/videoHeight与裁剪。

## 绘本世界与体感菜单

五款游戏采用本地毛毡绘本插画，贯穿大厅、准备、玩法说明、倒计时、试玩背景与结算。原图与完整提示词在 `assets/art/adventures-v1/`，运行图片与缩略图共约600 KB；现有童话道具继续使用原素材。

首次浏览器授权后自动启动识别。菜单会标出当前选项：单臂向屏幕左/右侧伸出保持0.55秒切换选项，胸前双手合拢保持0.85秒确认，双手交叉靠近对侧肩膀保持1.2秒返回。每个动作完成后，把双手放到胸口下方至少0.25秒，再做下一次；保持进度和动作小图示会显示在屏幕上。

确认/返回只用于菜单、准备、弹窗和结算；游戏内仍以游戏动作计分，五款均可指向暂停按钮停留。暂停弹窗做返回动作会继续当前局，结束须选中结束选项并确认。已连接返回大厅后可直接准备开玩，或通过“镜头设置”进入高级设备设置。选择设备、首次浏览器权限及精确数值裁剪仍可使用鼠标键盘。

新动效尊重系统减少动态效果设置；暂停、隐藏窗口和失去有效追踪时冻结游戏装饰。图片失败不阻断游戏。姿态数据只在内存使用，不记录身体坐标或摄像头影像。合成姿态和浏览器验证不代表PS4真机、电视延迟或家庭实测通过。


## 电视沉浸舞台

连接摄像头后的设备页、校准与五款游戏自动铺满视口，页头页脚收起；分数、时间、暂停和逐人进度悬浮在安全边距内，模仿动作卡保留为小窗。画面设置可展开，普通布局可恢复；试玩也可预览该布局。

真实点击连接摄像头时会尝试进入浏览器全屏；若浏览器拒绝，摄像头与体感仍可正常使用，点击「电视全屏」可再次进入。返回大厅保留连接；退出原生全屏会暂停正在进行的游戏。普通布局通过原头部全屏按钮重进沉浸，暂停菜单也提供电视全屏与返回普通布局。

游戏画布保持视频比例与原采集ROI，后台绘制限制在320万像素以内，识别调度不变；全屏电视性能与实际家庭体验仍需目标设备实测。

双人模式由开局确认时位于镜像画面右侧的伙伴主控菜单，画面以「主控伙伴」标记；确认、返回、指向暂停和抬手暂停只响应本人，换位不换人。重校准或再来一局重新分配，单人自己操作。

默认开启自由运动。游戏中短暂看不清手部或身体时，分别以最多250ms/400ms的真实历史补推动作，补推不用于菜单或初始确认。按各游戏实际依赖的身体部位保护任务时间与连击，不进行失败/危险物结算；不因无关肘点缺失停住拍泡泡、接爱心或穿星门。主控回来后先放松双手再操作菜单；恢复后稳定200ms。持续缺少任一必需伙伴约2.5秒才保留成绩暂停，画面回来即可继续。

准备时，只有举一只手高于肩膀并保持2秒的伙伴会绑定为本局参与者。多人同时争抢名额会等待确认。绑定后，路过、举手或占位的旁观者不会扩员；画面跟随、骨骼/头饰、计分和精细手点都经过同一名单。旁观者存在或手归属不明时使用绑定玩家的Pose腕点。普通进入校准保留名单，自由/严格模式共享身份；再来一局、重新绑定、人数/摄像头/裁剪变动才重新准备。
